# 🏠 空き家AIプランナー

全国の空き家データ × AIエージェント × 地図・PDFで、「この空き家をどう活かすか」を一緒に考えるWebアプリです。
**VORN Challenge 2026**（学生AIピッチコンテスト）への応募作品として、学生3人チームで開発しました。

## 解決したい課題

総務省「住宅・土地統計調査」（2023年）によると、全国の空き家数は899.5万戸と過去最高を更新し、総住宅数に占める空き家率は13.8%に達しています（[出典](https://www.nippon.com/ja/japan-data/h01987/)）。地方自治体の多くは空き家バンクや改修補助金制度を用意していますが、

- 空き家バンクの情報は自治体ごとにバラバラで、横断的に比較しづらい
- 「この空き家で何ができそうか」という活用イメージが湧きにくい
- 使える補助金・支援制度を自分で一つひとつ調べるのは手間がかかる
- 改修した場合にどのくらいの収支になるのか見積もりづらい

といった理由から、空き家の活用を具体的に検討するまでのハードルが高いのが実情です。本アプリは、この一連のプロセスをAIエージェントと地図・グラフ・AI画像生成でサポートし、「調べる→イメージする→試算する→提案する」までを一つの体験としてつなげることを目指しています。

## これは何？

- 🗺️ 地図から全国の空き家（約6,200件）を探せる
- 📍 物件ごとの構造・築年・間取り・周辺の生活環境（スーパー・駅・病院など）や観光・景観スポットを確認できる
- 💰 使える補助金・支援制度を自動表示（公式ページで内容を確認できたもの＝422件中410件・約97%のみを掲載し、情報の信頼性を担保）
- 📊 活用した場合の収支シミュレーションを5年分のグラフで確認
- 🎨 「どんな用途で」「どんな雰囲気で」活用したいかを伝えると、AIがその空き家の実際の特徴（構造・間取り・立地など）を踏まえた活用イメージ画像を生成（Gemini画像生成モデルを使用。現在調整中の機能です）
- 📄 選んだ物件の提案書をPDFで出力
- 💬 AIエージェントとチャット形式で対話しながら、やりたいことに合う空き家を検索→改修コスト概算→収支シミュレーション→補助金提案まで自律的に進めてもらうこともできる（Gemini function callingによるエージェント実装）

## 構成

このリポジトリは2つの独立したWebアプリ（別々にデプロイ）＋共通データで構成されています。学生3人チームで役割分担して開発し、エージェント設計・データ基盤・地図/PDF/画像生成UIをそれぞれ担当しました。

```
.
├── フロント/                      # 地図・物件一覧のフロントエンド（静的HTML/CSS/JS、Leaflet.js + Chart.js）
├── PDF出力/                       # ↑を配信するバックエンド（Flask）。物件API・補助金API・
│                                  # 周辺観光スポット検索・AI画像生成・提案書PDF出力を担当
├── エージェント設計/
│   └── akiya-ai-planner/          # AIエージェントによるチャットUI（FastAPI + Gemini function calling）
│       ├── agent.py               # エージェント本体（システムプロンプト・function calling制御）
│       ├── tools.py               # 空き家検索・改修コスト概算・収支シミュレーション・補助金検索の4ツール
│       ├── chat_cli.py            # CLI版チャット（動作確認用）
│       └── web/                   # Web版チャットUI
├── data/                          # 空き家・補助金データの生成スクリプトとSQLシード
├── schema.sql / empty_house.db    # SQLiteデータベース（空き家 約6,200件・補助金 422件）
└── 空き家AIプランナー.command       # ローカルで地図アプリをワンクリック起動するmacOS用スクリプト
```

## セットアップ（ローカルで動かす）

### 必要なもの

- Python 3.10 以上
- Gemini APIキー（[Google AI Studio](https://aistudio.google.com/apikey)で無料取得可能）
- （任意）Google Places APIキー：空き家周辺の観光・景観スポット表示に使用。未設定でもその機能が無効になるだけで、他は動きます

### 1. 地図・物件検索アプリ（`PDF出力/` + `フロント/`）

```bash
cd "PDF出力"
pip install -r requirements.txt

# リポジトリ直下に .env を作成し、以下を設定
# GEMINI_API_KEY=xxxxx
# GOOGLE_PLACES_API_KEY=xxxxx （任意）

python3 app.py
```

`http://localhost:8080` を開くと地図アプリが立ち上がります。macOSなら、リポジトリ直下の `空き家AIプランナー.command` をダブルクリックするだけでも起動できます（同じWi-Fi内の人にURLを共有してデモする用途を想定しています）。

### 2. AIチャット相談アプリ（`エージェント設計/akiya-ai-planner/`）

```bash
cd "エージェント設計/akiya-ai-planner"
pip install -r requirements.txt
cp .env.example .env
# .env の GEMINI_API_KEY にAPIキーを設定

python3 chat_cli.py          # CLIで試す場合
# もしくは
uvicorn web.app:app --reload --port 8000   # Web版
```

詳しくは [`エージェント設計/akiya-ai-planner/README.md`](エージェント設計/akiya-ai-planner/README.md) を参照してください。

## デプロイ

[Render](https://render.com) 上に、2つのWebサービスとして個別にデプロイしています（どちらもこのリポジトリの `waka1` ブランチから自動デプロイ）。

| サービス | 内容 | Start Command |
| --- | --- | --- |
| `Empty_house2026-1` | 地図・物件検索アプリ | `cd "PDF出力" && gunicorn --bind 0.0.0.0:$PORT --timeout 240 app:app` |
| `Empty_house2026` | AIチャット相談アプリ | `cd "エージェント設計/akiya-ai-planner" && uvicorn web.app:app --host 0.0.0.0 --port $PORT` |

環境変数（Render側の Environment で設定）：

| 変数名 | 用途 | 必須 |
| --- | --- | --- |
| `GEMINI_API_KEY` | AIチャット応答・活用イメージ画像生成（Gemini API） | ✅ |
| `GOOGLE_PLACES_API_KEY` | 空き家周辺の観光・景観スポット表示 | 任意（未設定時はその機能のみ無効） |

## 使っている技術

- **フロントエンド**: 素のHTML/CSS/JS、Tailwind CSS、Leaflet.js（地図）、Chart.js（グラフ）
- **バックエンド**: Flask（地図・PDF出力）、FastAPI（チャット）、gunicorn / uvicorn
- **AI**: Gemini API — チャットのfunction calling（空き家検索・改修コスト概算・収支シミュレーション・補助金検索の4ツールを自律的に呼び出す）、活用イメージ画像生成（Nano Banana系モデル）
- **データ**: SQLite（空き家 約6,200件・全国の空き家バンク等から収集、補助金422件・うち410件は公式ページURLまで確認済み＝約97%）
- **PDF生成**: ReportLab

## 既知の制限事項

- **活用イメージ生成（AI画像）機能は現在調整中です。** Geminiの応答に時間がかかったり、混雑時（429エラー）に失敗したりすることがあります。失敗した場合はしばらく待ってからもう一度お試しください。
- 無料プランでホスティングしているため、しばらくアクセスがないとアプリがスリープし、最初のアクセス時に起動まで時間がかかります。
- 収支シミュレーション・改修コスト概算は簡易的な数式によるプレースホルダーです。実在の制度・金額として案内しないようご注意ください。
- 補助金情報は、公式ページのURLで内容を確認できたもの（422件中410件、約97%）のみ表示する方針にしています。確認が取れなかった補助金は、誤った情報を案内しないよう意図的に非表示にしています。
